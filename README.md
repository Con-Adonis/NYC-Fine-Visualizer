# NYC-Fine-Visualizer

## Installation Steps

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

## Data Sourcing
Data scraped from the Office of Administrative Trials and Hearings (OATH) Hearings and Division Case Status via NYC Open Data
https://data.cityofnewyork.us/City-Government/OATH-Hearings-Division-Case-Status/jz4z-kudi
Dataset updated from 2013 to present
